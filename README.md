# Учёт зарплаты — Android

Простое Android-приложение для ручного учёта зарплаты по месяцам.

## Возможности
- Ввод суммы за каждый из 12 месяцев.
- Сохранение данных на телефоне.
- Переключение между годами.
- Автоматический подсчёт суммы за год и среднего за месяц.
- Работа без интернета после установки.

## Сборка APK через GitHub Actions (можно начать с телефона)
1. Создайте репозиторий на https://github.com (кнопка New repository).
2. Загрузите содержимое этой папки в репозиторий, сохранив структуру каталогов.
3. Откройте вкладку Actions и дождитесь завершения задачи **Build Android APK**.
4. Откройте завершённый запуск workflow, внизу скачайте артефакт `salary-tracker-apk`.
5. Распакуйте архив и установите `app-debug.apk`. При запросе Android разрешите установку приложений из этого источника.

## Локальная сборка
Нужны Android Studio, JDK 17 и Android SDK 35. Выполнить `gradle assembleDebug`.
APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Примечание: данные сохраняются локально в памяти приложения. При удалении приложения данные могут быть удалены.
